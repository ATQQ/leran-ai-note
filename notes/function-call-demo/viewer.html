字段说明

usage
本轮 API 返回的 token 统计（如 prompt_tokens / completion_tokens / total_tokens）。不是密钥，回放时会完整展示，便于对照成本与上下文长度。
tool_choice
控制「要不要 / 必须调哪个工具」。OpenAI：auto（默认，模型自决）、none（禁止）、required（必须调）、或指定某个函数。Anthropic：{type:"auto"|"any"|"tool"|"none"}。
additionalProperties
工具参数的 JSON Schema 开关。设为 false 时禁止声明之外的多余字段，减少模型乱传参（例如多塞一个无关 key）。
reasoning_content
部分推理模型或中转站在 assistant 消息上扩展的字段，表示思考过程文本。用户可见答案一般在 content；是否调工具看 tool_calls。官方标准 Chat Completions 不一定有此字段，回放时若存在会单独展开。
