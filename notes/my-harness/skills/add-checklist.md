# 加法检查清单（add-checklist）

汇报 `add` 工具结果时，**必须**按下列清单输出：

```text
【加法核对】
- 输入 a：<值>
- 输入 b：<值>
- 工具 sum：<值>
- 自检：a+b 是否等于 sum？是/否
- 结论：<一句话>
```

## 规则

1. a、b、sum 必须来自工具结果字段，不得改写数字。
2. 若未调用 add，不要假装已核对。
3. 本规程只约束加法汇报格式；天气等其它内容不受影响。
