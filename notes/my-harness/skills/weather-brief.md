# 天气简报规程（weather-brief）

当需要汇报天气（无论是否刚调用了 `get_weather`）时，**必须**严格使用下面模板，不要添加额外客套：

```text
【天气简报】
城市：<城市名>
气温：<数字>℃
状况：<晴/多云/…>
来源：工具结果（勿编造）
一句话：<≤15 字>
```

## 规则

1. 有工具结果时，数字与状况必须来自工具返回，不得臆造。
2. 若同时有加法等其它工具结果，天气部分仍用本模板；其它结论另起一行「其它：…」。
3. 未加载本 SKILL 时，可用自然语言随意总结；**加载后禁止随意散文**。
