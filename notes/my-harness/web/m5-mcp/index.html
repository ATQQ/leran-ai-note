①b JSON-RPC 格式（stdio 一行一帧） stdout 专给协议

交互发生在 Host↔子进程的管道上：Host 写 Server 的 stdin，读 Server 的 stdout。 console.log 会污染协议；日志用 stderr。

请求（有 id = 要响应）
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "read_file",
    "arguments": { "path": "hello.txt" }
  }
}
成功响应（同 id）
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "content": [{ "type": "text", "text": "…" }],
    "isError": false
  }
}
通知（无 id，不期待响应）
{
  "jsonrpc": "2.0",
  "method": "notifications/initialized",
  "params": {}
}
